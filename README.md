# 오로라 레일

정비례·반비례 관계로 이동할 역을 고르고 두 종류 승차권을 남기는 중1 수학 경로 퍼즐입니다. 12개 여행, 별 수집과 배지, 되돌리기·재시작, 화면 집중 연습을 제공합니다. 학생 대상 재미·학습 효과는 아직 검증하지 않았습니다.

`npm test`, `npm run build`, `npm start`로 독립 실행합니다. Vercel에서 저장소를 Import하면 `dist` 정적 배포가 가능합니다. 기본 개발 포트는 51245입니다.

본 게임의 역은 제1사분면에 한정됩니다. `assessment/`는 새로운 수·상황, 표·식·그래프와 설명 기록을 별도로 확인합니다. 익명 노트를 여러 개 만들 수 있고 브라우저에만 저장됩니다. 로그인이나 다른 기기 간 동기화는 제공하지 않습니다. 읽기 쉬운 HTML 내보내기와 인쇄를 제공합니다. 출처와 범위는 `assessment.json`, `sources.json`, 기획은 `design.json`에 기록합니다. 원본 PDF·추출문은 포함하지 않습니다.
